# Memory — Personal Assistant

Trvalé fakty a preference o uživateli/kontextu, které mají platit napříč sessions bez
ohledu na to, co spadlo z `chat_history.txt`. Jiná kategorie než `DECISIONS.md` — tam
patří technická/architektonická rozhodnutí, sem patří fakty o uživateli a jeho preferencích
(např. styl komunikace, probíhající projekty, opakující se kontext).

Doplňuje se průběžně, jen když se objeví něco, co stojí za zapamatování — ne po každé
zprávě. Nejde o transkript konverzace, jde o destilovaný, kurátorovaný obsah: krátké,
celé věty, ne scratchpad.
